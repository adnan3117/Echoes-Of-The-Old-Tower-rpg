# Echoes of the Old Tower RPG

A console-based RPG game developed in C for the CSE103 – Structured Programming course.

## About the Project

**Echoes of the Old Tower** is a text-based RPG featuring exploration, combat, quizzes, inventory management, player progression, and save/load functionality.

The project was developed to practice structured programming concepts and C programming.

## Features

- Console-based RPG gameplay
- Story Mode
- Free World Mode
- Player progression and XP
- Combat system
- Multiple weapons and items
- Inventory management
- Quiz system
- Save and load functionality
- Randomized events and questions

## Technologies

- **Language:** C
- **Paradigm:** Structured Programming
- **Interface:** Console / Terminal
- **Compiler:** GCC
